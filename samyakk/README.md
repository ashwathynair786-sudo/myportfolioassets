# Samyakk

Brand identity, store revamp and collateral for Samyakk, a wedding destination store in Richmond Town, Bengaluru.

Open `preview/index.html` to see the case study as a page.

## Folders

| Folder | What's in it |
| --- | --- |
| `logo/` | `samyakk-logo-master.pdf` is the vector master from Illustrator. From it: `samyakk-logo.svg` and `.png` (transparent), `samyakk-lotus-mark.svg` and `.png`, and `samyakk-logo-clear-space.svg` (construction grid, clear space X = height of the lotus crown). Also the old brand sheet and the previous logo for before/after. |
| `collateral/stationery/` | Business cards (the cover image). |
| `collateral/packaging/` | Bridal box (front and angle), saree box, tissue wrap and boxes. |
| `collateral/retail/` | Jute tote bags. |
| `collateral/pattern/` | Chevron and lotus pattern. |
| `collateral/palette/` | Colour palette board. |
| `collateral/logo-in-use/` | Gold foil lotus mark, logo on kraft. |
| `archive/old-collateral/` | The earlier collateral set (stationery, retail, packaging and cut-outs), replaced by the current set. |
| `source/` | The two original presentation PDFs the mockups were extracted from. |
| `preview/` | The HTML case study and its web-sized images (`preview/img/`). |
| `stores/` | Store photos: the bridal arch, the lotus floor display and the wordmark at the trial room. These are small (about 550px wide); larger originals would sharpen the page. |

## What changed in the cleanup

The original uploads had four exact duplicates (`samyakk revamp 2.pdf`, `samyakk updated 2.pdf`, and two identical ChatGPT images), which were removed. `brand-samyakk-1/2/3.jpg` were lower-resolution copies of mockups that are also inside the PDFs, so the higher-resolution versions were extracted and kept instead. The jute bag photo was the one exception: its upload was larger than the PDF copy, so it was kept with a stray edge strip cropped off.

The first logo files were taken from an 820px PNG. They were replaced by the vector master (`samyakk new logo .pdf`), and the old raster logo, transparent PNG and clear-space image were removed.
