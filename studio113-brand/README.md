# Studio 113 · House of Kanchana — portfolio boards

Brand identity case study built from `STUDIO 113 BRAND DOC (1).pdf` and `logos.pdf`.

- `studio113-brand-book.html` — every board on one page (open in a browser). Each `<section class="board">` is one export.
- `portfolio/` — the exports for the portfolio site
  - `studio113-01` … `studio113-22` boards (`.webp`, square 1600 px or wide 3200 px)
  - `studio113-thumbnail.webp` (16:10)
  - `studio113-logo-loop.mp4` / `.webm` + `studio113-logo-loop-poster.jpg` (stamp drops, gets franked, wordmark rises; 4.5 s loop)
- `assets/` — logo files (stamp black / teal, one-colour ink, wordmark black / cream, IvyPresto specimen), photography and mockups pulled from the PDFs
- `export_boards.mjs` — re-export boards: `NODE_PATH=$(npm root -g) node export_boards.mjs [scale] [name-filter]`
- `logo-loop/` — `loop.html` + `render_loop.mjs` to re-render the logo video
